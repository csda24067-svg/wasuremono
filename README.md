# 🎒 忘れ物確認Webアプリ

外出する前に必要な持ち物をチェックし、忘れ物を防ぐためのWebアプリケーションです。
外出先ごとに持ち物リストを管理し、すべての項目にチェックが入ると「準備完了」と表示されます。

大学PBL（Project Based Learning）の課題として、要件定義・設計（クラス図、シーケンス図、状態遷移図、ユースケース図）に基づいて開発しました。

## 主な機能

### 基本機能（要件定義に基づく）

| 機能 | 内容 |
| --- | --- |
| 外出先の登録・削除 | 学校、旅行などの行き先を管理 |
| 持ち物の登録・削除 | 外出先ごとに必要な持ち物を管理 |
| チェック機能 | 持ち物ごとに「チェック済み / 未チェック」を切り替え |
| 準備完了表示 | 全項目チェックで「✅ 準備完了！」を表示（紙吹雪つき） |
| 未チェック強調 | 未チェックの持ち物を件数・品名つきで警告表示 |
| チェックリセット | 次回の外出に向けて全項目を未チェックに戻す |
| CSV保存・読み込み | データはCSVファイルに自動保存され、再起動後も保持 |
| 入力検証 | 未入力・重複登録などをエラーメッセージで通知 |

### 拡張機能（要件達成後に追加）

| 機能 | 内容 |
| --- | --- |
| 予定日の管理 | 外出先に予定日を設定・変更・削除できる |
| 今日の予定の強調 | 予定日が今日の外出先を最上部に赤いバッジつきで表示 |
| 残り日数表示 | 「あと3日」のように予定日までの日数を表示 |
| 現在日時の表示 | トップ画面に日付と秒単位で動く時計を表示 |
| 進捗バー | 準備の進み具合（例: 2/5件）を視覚的に表示 |

## 画面イメージ

- **トップ画面** … 外出先を荷札（ラゲッジタグ）風のカードで一覧表示。今日の予定は目立つデザインで最上部に。
- **持ち物管理画面** … 持ち物の追加・チェック・削除と進捗バー。全部チェックすると準備完了の演出。

## セットアップと実行方法

### 1. 必要なもの

- Python 3.8 以上

### 2. インストール

```bash
git clone https://github.com/csda24067-svg/wasuremono-app.git
cd wasuremono-app
pip install Flask
```

### 3. 起動

```bash
python app.py
```

起動後、ブラウザで次のURLを開いてください。

```
http://127.0.0.1:5000
```

停止するときはターミナルで `Ctrl + C` を押します。

## 使い方

1. トップ画面で外出先（例: 学校）を登録する（予定日は任意）
2. 外出先を開き、持ち物（例: 学生証、ノート）を登録する
3. 外出前に、準備できたものから「チェックする」を押す
4. すべてチェックすると「✅ 準備完了！」が表示される
5. 帰宅後は「🔄 チェックをリセット」で次回に備える

## データ形式（CSV）

データは `data.csv` に次の形式で保存されます（アプリが自動生成するためリポジトリには含みません）。

```csv
外出先,持ち物,チェック状態,予定日
学校,学生証,チェック済み,2026-07-02
学校,ノート,未チェック,2026-07-02
旅行,財布,未チェック,
```

※「予定日」列は拡張機能で追加した項目です。旧形式（3列）のCSVもそのまま読み込めます。
